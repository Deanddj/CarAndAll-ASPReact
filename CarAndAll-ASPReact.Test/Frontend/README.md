Lighthouse Test

Dit project bevat een setup om Lighthouse-prestatietests uit te voeren op je website.

1. Voer de volgende opdracht uit om de benodigde pakketten te installeren:

(npm install)

2. Voer Lighthouse-tests uit

Om de Lighthouse-tests voor je website uit te voeren, gebruik je de volgende opdracht:

(npm run lighthouse/lighthouse-single)

Dit genereert een rapport en slaat het op als (samengestelde-)lighthouse-report.html in de projectmap.

3. Het rapport bekijken

Open (samengestelde-)lighthouse-report.html in je browser om de resultaten van de Lighthouse-testen te bekijken.
